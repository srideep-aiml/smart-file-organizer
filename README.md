# Smart File Organizer 📁

## About the Project
Smart File Organizer is a Python-based project that automatically organizes files into different folders based on their file types. It helps keep files organized and makes them easier to find.

## Features
- Automatically organizes files into folders.
- Separates images, documents, videos, music, and other file types.
- Avoids filename conflicts.
- Handles file errors.
- Saves time and reduces manual work.

## Technologies Used
- Python
- OS module
- Shutil module
- Pathlib module

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file using the terminal.

```bash
python smart_file_organizer.py
```
